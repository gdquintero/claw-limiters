## Kemm 2011 — key content
- Framework: van Leer REA scheme I, piecewise linear recon, slope s_i = M(Δup/Δx, Δdown/Δx), mean M with normal form Φ(r)=M(r,1), r = Δq_up/Δq_down.
  For a>0: r_i = Δq_{i-1/2}/Δq_{i+1/2}. Equals LeVeque's θ_{i+1/2} (flux-limiter at interface i+1/2): s_iΔx = Φ(r_i)Δq_{i+1/2}.
- Scheme (9): q_i^{n+1} = q_i^n − [ν + ½ν(1−ν)(Φ(r_i)/r_i − Φ(r_{i−1}))] Δq_{i−1/2}.
  Φ≡1 Lax–Wendroff; Φ=r Beam–Warming; Φ=(1+r)/2 Fromm. All on Fromm 4-pt stencil. Linear Φ ⇒ linear scheme.
- Mean properties: (M1) consistency Φ(1)=1, (M2) inclusion min(r,1)≤Φ≤max(r,1), (M3) homogeneity, (M4) symmetry Φ(1/r)=Φ(r)/r, (M5) monotonicity.
- Roe linear theory: Thm1 linear schemes order p with m-pt support: m−p−1 parameter family. 4-pt ⇒ 2nd-order schemes = 1-param family (LW–BW blends). Thm2: (1−(1+ν)/3)LW + ((1+ν)/3)BW is 3rd order ⇒ Φ_3(r) = 1 + (1+|ν|)/3 (r−1)   [in LeVeque θ: φ=(2−ν)/3+(1+ν)/3 θ]. Not symmetric → sacrifice M4.
  Arora–Roe: Φ(1+ε)=1+O(ε) ⇒ 2nd order. Roe [7]: Φ(1+ε)=Φ_3(1+ε)+O(ε²) ⇒ 3rd-order behaviour in smooth monotone regions.
  Thm3 (Roe): single Fourier mode — even order p: phase O(p), amplitude O(p+2); odd p: both O(p+1). ⇒ 2nd-order TVD: phase error dominates (shape distortion); 3rd-order: both 4th.
- Harten TVD thm (C,D≥0, C+D≤1). General TVD condition (17), CFL-dependent:
  −2/(1−|ν|) ≤ Φ(r)/r − Φ(R) ≤ 2/|ν|   ∀ r,R.
  Restricted (Sweby) TVD (18): −2 ≤ Φ(r)/r − Φ(R) ≤ 2 (needed for semi-discrete / reconstruction-TVD; limits ν→0 and ν→1).
  Upper bound Φ_UB = max(0,min(2r/|ν|, 2/(1−|ν|))) (Toro calls it Ultrabee; first order, squaring). Φ≡0 upwind.
  Φ(0)=0 for TVD. Semi-discrete: Φ_{3,0}=1+(r−1)/3 (Artebrant–Schroll); Sweby bound max(0,min(2r,2)).
- "Compressive" = tends to squaring vs smearing. Tuning artificial compression is essential.
- Families: MC (van Leer 77) → Arora–Roe Φ_AR = max(0,min(Φ_UB, Φ_3)); θ-versions (θ∈[1/2,1], multiply UB by θ), θ-version allowing negative values (reconstruct extrema) eq (40).
  Superbee family: CFL-Superbee (=Roe's Ultrabee) min(UB, max(1,r)); new β-modified CFL-Superbee eq (43) adapted to 3rd order slope at r=1; β=2/3 preserves M2, M5; Harten shock switch ψ(r)=|1−r|/(1+|r|) to blend limiters / pick β=1/3+2/3ψ.
  Smooth: Hyperbee (Roe; advects exponential exactly; slope at r=1 = 3rd order; sharply TVD), van Leer = harmonic mean; Serna–Marquina power mean: Φ=max(0,(1+r)/2 (1 − |(1−|r|)/(1+|r|)|^p)); p=1 minmod, p=2 vL; CFL-dependent p on each side; Superpower (eq 57-58) = Φ_3·(1 − |(1−|r|)/(1+|r|)|^{p(r)}), p(r)=2/|ν|·... ; Hyperpower = max(Superpower,Hyperbee). Klein sharpening. van Albada (r+r²)/(1+r²); Albada-p generalization; Albada 3 sharply satisfies restricted TVD; OSPRE.
  Čada–Torrilhon (log-limiter, non-TVD, semi-discrete, 3rd order); Kemm CFL-adapted modification ČT_mod; Čada switch for smooth extrema (asymptotic radius issue — breaks homogeneity M3).
- Tests (all in CLAWPACK, wave limiting = algebraic limiting applied to waves of Riemann solutions): Zalesak/Jiang–Shu test (Gaussians, square, triangle, half ellipse), 200 cells, t=20 (10 periods), ν=0.1,0.5,0.9. Convergence: sin(6πx) on [-1,1], T=8, L2, 100…25600 cells.
  Results: no limited scheme shows full 2nd order (clipping at extrema dominates on fine grids); Superbee squaring → poor convergence; Arora–Roe best limited (near 3rd on coarse); β=2/3 best compromise; CFL-Superbee for piecewise linear/linear waves; Superpower/θ-AR for nonlinear waves. Euler: Woodward–Colella blast, Shu–Osher, 2D Riemann, Toro implosion, Gresho vortex. Mixed limiters per wave family.
- Open points stated: "search for optimal smooth limiter is still open"; switch parameter choice unresolved; transfer to unstructured grids; primitive vs characteristic limiting.
- NB: Kemm evaluates limiters only by figures + L2 convergence; no spectral (dispersion/dissipation) analysis of the nonlinear limited schemes.

## Lele 1992 — key content
- Compact (Padé-type) FD: β f'_{i−2} + α f'_{i−1} + f'_i + α f'_{i+1} + β f'_{i+2} = c(f_{i+3}−f_{i−3})/(6h) + b(f_{i+2}−f_{i−2})/(4h) + a(f_{i+1}−f_{i−1})/(2h).
  Taylor constraints (2.1.1–2.1.5). Families: 4th-order tridiag (α param), classical Padé α=1/4 (a=3/2), 6th-order tridiag α=1/3 (a=14/9, b=1/9), 8th, 10th pentadiag (α=1/2, β=1/20, a=17/12, b=101/150, c=1/100).
- Fourier analysis: scaled wavenumber w=2πk/N ∈[0,π]; modified wavenumber w'(w) = [a sin w + (b/2) sin 2w + (c/3) sin 3w]/[1+2α cos w+2β cos 2w]. Central ⇒ w' real ⇒ purely dispersive.
  Resolving efficiency e(ε)=w_f/π where |w'(w)−w|/w ≤ ε. Table III (e.g. CD2 0.08 @ε=0.01; spectral-like 0.83).
  Spectral-like scheme: impose w'(w_j)=w_j at w=2.2,2.3,2.4 (formally 4th order): α=0.5771439, β=0.0896406, a=1.3025166, b=0.9935500, c=0.03750245.
  Key philosophical point: optimizing in Fourier space beats maximizing formal order; resolution of short scales insensitive to formal order. Lower-order member (α≈... 4th order) better resolution than 6th-order Padé.
- Phase speed c_p = w'/w; 2D anisotropy c_p(w,θ) = [cosθ w'(w cosθ) + sinθ w'(w sinθ)]/w.
- Second derivative: w''(w) formula (3.1.10); spectral-like 2nd-deriv scheme.
- Aliasing caveat for nonlinear problems; dealiasing/filtering.
- Boundary schemes (4.1): one-sided compact, complex modified wavenumber (real part = dispersion, imag = dissipation). Conservative boundary formulation (global conservation; implied quadrature weights). Eigenvalue analysis (method of lines) — least-damped eigenvalue → imag axis like N^-3; boundary accuracy increase shifts spectrum left.
- Explicit time-step limits: σ_I/w'_max (RK3 √3, RK4 2.85 (2√2)); diffusion σ_R/w''_max.
- Apps: compressible mixing layer, shock structure (viscous scale). Explicitly: NOT monotone/TVD; step function → 2Δ oscillations exponentially damped (vs Gibbs algebraic). Restricted to smooth solutions.
- Appendix B: cell-centered (staggered) compact schemes — better near w=π; relevant to finite volumes. Appendix C: compact midpoint interpolation (transfer function T(w)), compact filters (T(π)=0), spectral-like interpolation.

## Pereira & Pereira 2001 — key content
- von Neumann analysis of 1D convection–diffusion: Up1, Up3, Up5 (Rai–Moin), CD2, CD4, compact CdC4 (Lele Padé) + RK1/2/4/6; AB2, Leapfrog/DuFort–Frankel, QUICKEST (Leonard).
- Amplification factor G(θ;c,k) with c=aΔt/Δx (Courant), k=νΔt/Δx² (diffusion number). Stability diagrams in (c,k) plane; upwind: c decreases linearly with k; central: max diffusive limit at c>0; RK4 with central stable for pure convection.
- Spectral error analysis: dissipation |G| vs exact 1; dispersion arg(G) vs −cθ; group velocity d(kâ)/dk; negative group velocity of short waves (spurious oscillations propagate at group vel.).
- Numerical test: C∞ bump exp(−1/((x−1/4)(3/4−x))) after 2 periods, 50 nodes, c=0.5.
- Conclusion: RK4 + compact 4th best spectral resolution; upwind odd-order p dispersion ≈ central p+1 for c≤0.5. QUICKEST exact at c=1, dispersion-free at c=0.5.
- Purely linear schemes — no limiters.

## SYNTHESIS / connections / gaps (my analysis)
- Notation map: Kemm Φ(r), r_i=Δq_{i−1/2}/Δq_{i+1/2}  ≡  LeVeque φ(θ_{i+1/2}); Kemm (9) ≡ LeVeque (6.40). Kemm Φ_3 = (2−ν)/3+(1+ν)/3 θ in LeVeque notation. CLAWPACK limiter is applied to waves (algebraic) with θ by projection (limiter.f/philim.f), mthlim 1..4 are CFL-independent.
- TVD region: LeVeque/Sweby use CFL-independent 0≤φ≤minmod(2,2θ); Kemm uses the full CFL-dependent bound −2/(1−ν)≤φ(r)/r−φ(R)≤2/ν.
- Linear members φ=a+bθ (LW, BW, Fromm, Φ_3) admit exact von Neumann G(ξ,ν) ⇒ dispersion/dissipation à la Pereira; Roe's theorem on phase/amplitude orders. Limited schemes are nonlinear ⇒ classical von Neumann/modified wavenumber not applicable (LeVeque §20.4 remark). Kemm evaluates limiters only via tests + L2 convergence; no spectral (dispersion/dissipation/resolving-efficiency) characterization of limited schemes in the material.
- Homogeneity (M3) ⇒ response of limited scheme to A·sin(kx) is amplitude-independent ⇒ a per-wavenumber "effective amplification factor" (nonlinear modified wavenumber / ADR-type) is well-defined, though harmonics are generated (θ<0 at extrema → clipping).
